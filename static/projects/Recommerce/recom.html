Confidential Project "Recommerce"
JavaScript Cypress Azure DevOps E2E Testing Release Management

Supported the development and automation of a recommerce platform. The project focused on building a robust, continuous testing framework to validate the entire product lifecycle, from warehouse intake to technical assessment.

My main activities involved:

  • Designed and implemented an end-to-end (E2E) test suite using Cypress, covering critical platform flows, ensuring UI integrity and the accuracy of complex business rules.
  • Automated test scenarios to validate "grading" criteria (product condition) and hardware functionality, ensuring the system correctly recorded the status of incoming tech items.
  • Collaborated with the development team to integrate automated tests into the CI/CD pipeline using Azure DevOps, enabling continuous validation of new features and bug fixes.
